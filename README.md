QUARTERS 2.0

A mobile-first student accommodation and roommate discovery platform, initially focused on Nigeria.

Project Principles

* Build a mobile-first, accessible interface.
* Use Supabase for authentication, database, storage, and backend functionality.
* Keep application code and database migrations version-controlled.
* Enforce authorization and data access rules on the server.
* Clearly distinguish sample data from real listings and user activity.
* Never report a successful operation unless it actually succeeds.

Development

The application framework and initial project structure will be established during Stage 0.

Project Status

Currently in Stage 0: Foundation.
